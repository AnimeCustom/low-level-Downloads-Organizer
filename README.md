# low level Downloads Organizer
This Application organizes your Downloads folder, because mine always looks like shit :D

How it Works:

1. Open the .exe file
2. the program automatically recognizes your file types
3. select a folder for every filetype or ignore them (stays in the downloads folder without any changes)
4. You can also add your own folder names and select them
5. click on organize
6. now you have a basis to organize further manually without digging through all the files at once.
